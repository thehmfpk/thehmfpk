# About Me

I am a **Software Engineering enthusiast** focused on building impactful, scalable, and intelligent digital solutions. My expertise spans **Full-Stack Development, Artificial Intelligence, UI/UX Design, and Intelligent Automation**.

Currently working as a **Full-Stack Developer at 10Pearls Pakistan**, participating in the **10Pearls Shine Internship Program – Cohort 10**, where I focus on modern MERN stack development and real-world software engineering practices.

I specialize in integrating artificial intelligence and software engineering principles to:

- Build intelligent automation agents and AI-driven systems
- Develop conversational AI chatbots and assistants
- Create data-driven user experiences and analytics dashboards
- Optimize workflows using automation platforms (n8n, AI agents)
- Develop scalable full-stack web applications (MERN)
- Integrate LLMs, APIs, and Retrieval-Augmented Generation (RAG)
- Apply Software Quality Engineering (SQA) for reliable systems
- Design robust software architectures and modular systems
- Transform business processes through intelligent automation
- Deliver end-to-end digital products from concept to deployment

Beyond development, I serve as **President of the LGU SE Tech Society**, contributing to technical initiatives, team coordination, and technology-driven community development.

My approach combines **clean code, modern design, intelligent engineering, and measurable outcomes**.
